# AI/ML-Based Predictive Maintenance and Vehicle Health Monitoring System

## 📌 Project Overview

This project presents an **AI/ML-based predictive maintenance system** designed to monitor vehicle health and predict the possibility of component failure before it occurs.

The system uses vehicle sensor parameters such as engine temperature, RPM, oil pressure, vibration, battery voltage, coolant temperature, fuel consumption, vehicle speed, and operating hours to estimate vehicle health and failure probability.

## 🎯 Objectives

* Predict potential vehicle/component failure before it occurs.
* Analyze important vehicle sensor parameters.
* Compare different Machine Learning and Deep Learning models.
* Generate a vehicle health score and failure probability.
* Provide maintenance alerts based on the predicted vehicle condition.
* Identify major factors contributing to potential failure.

## 🧠 Models Used

### Machine Learning

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost

### Deep Learning

* LSTM
* GRU
* Transformer

## 📊 Input Parameters

The dataset contains the following vehicle parameters:

* Engine Temperature
* RPM
* Oil Pressure
* Vibration
* Battery Voltage
* Coolant Temperature
* Fuel Consumption
* Vehicle Speed
* Operating Hours
* Failure

## ⚙️ System Architecture

**Vehicle Sensors → Data Preprocessing → ML/DL Models → Failure Probability → Vehicle Health Score → Maintenance Alert**

## 📈 Expected Output

The system provides:

* **Vehicle Health Score**
* **Failure Probability**
* **Vehicle Status**
* **Maintenance Alert**
* **Major Contributing Factors**

Example:

```text
Vehicle Health: 72%
Failure Probability: 68%
Status: WARNING

Major Contributing Factors:
1. High vibration
2. Rising temperature
3. Abnormal oil pressure
```
